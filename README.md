# 🐕 Maddie's Treat Catch

A cute little browser game starring **Maddie** — a pitbull-beagle mix who loves treats!
Move Maddie around to catch her favorite treats — 🦴 bones and 🧈 butter — before they hit the ground.

Made by Emma 💛

## 🎮 How to play
- **Move Maddie:** drag / move your mouse, or use the **← →** arrow keys
- **Catch treats** to score points — 🧈 butter is worth big points!
- **Don't miss!** A dropped treat costs a life (and butter catches build up a combo multiplier)
- The treats fall faster the longer you survive

## 🕹️ Game modes
- **🐾 Classic** — 3 lives, don't miss a treat
- **⏱️ Time Attack** — 60-second rush; each miss knocks off 2 seconds
- **🧘 Zen** — no fails, just vibe and catch
- **🔥 Hard** — 1 life, treats fall fast

## ▶️ Play it
Just open `index.html` in any web browser — that's it. No installs, no setup.

If this repo has **GitHub Pages** turned on, you can play it online at:
`https://<your-username>.github.io/maddies-treat-catch/`

## 🛠️ Built with
Plain HTML, CSS, and JavaScript (HTML5 Canvas) — one single file, no libraries.
